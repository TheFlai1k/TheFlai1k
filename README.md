# TheFlai1k (Fabric, Minecraft 1.21.8)

1. Upload ALL files of this folder to the root of a GitHub repository.
2. Open the Actions tab -> "Build TheFlai1k" -> wait for the green check.
3. Open the finished run -> Artifacts -> TheFlai1k-mod -> unzip -> put theflai1k-1.0.0.jar into .minecraft/mods
   (needs Fabric Loader + Fabric API for 1.21.8).

In game: Right Shift opens the menu (change it in Controls). V = radial menu, C = zoom (hold).
Chat commands: .help .gps .friend .wp .coords
